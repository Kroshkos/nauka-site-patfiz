# Контур 2 · Сайт научных мероприятий ВМедА

🌐 **https://nauka-site-patfiz.waw0.amvera.tech**

Публичный портал мероприятий академии: конференции, семинары, вебинары, школы молодого учёного, конкурсы и выставки. Полностью переработан в единую дизайн-систему с Контуром 1.


## Возможности
- 🏠 **Главная** — герой-блок со статистикой, featured-событие, ближайшие карточки, лента новостей
- 🗂 **Каталог** — 12+ мероприятий, живой поиск, фильтры по формату/организатору, сортировка (дата / популярность / остатки мест)
- 📅 **Календарь** — месячная сетка 2026 с цветовой маркировкой форматов, клик по дню → список событий
- ✅ **Регистрация** — форма с валидацией ФИО/e-mail, статусы «открыта / скоро старт / мест нет / завершено», лист ожидания
- ❤️ **Избранное и «Мои события»** — сохраняются в localStorage; экспорт события в календарь (**.ics**)
- 🔗 шеринг ссылкой (`#e{id}` — прямое открытие модалки), тёмная/светлая тема, адаптив под мобильные
- 🏢 **Организаторам** — описание интеграции: мероприятия публикуются через [Контур 1](https://github.com/Kroshkos/nauka-sistem-patfiz), заявки возвращаются в отчёты кафедр

## Структура
```
public/            # статический сайт (раздаётся server.py на Amvera)
├── index.html     # точка входа SPA
├── css/style.css  # дизайн-система (единая с Контуром 1)
├── js/data.js     # данные мероприятий, типы, организаторы
├── js/app.js      # рендер, роутинг, регистрация, избранное, календарь
└── assets/legacy-demo.html  # прежняя демо-версия
server.py · amvera.yml       # python-статика, порт 8080
demo/                        # исходное демо из общего репозитория
```

## Локальный запуск
```bash
cd public && python3 -m http.server 8080
# открыть http://localhost:8080
```

## Деплой на Amvera
Репозиторий импортирован в Amvera — запуск через `server.py` (Python http.server), порт 8080. Push в `main` = автодеплой.

## 🔗 Интеграция с Контуром 1

Каталог мероприятий доступен в машиночитаемом виде:

- **`GET /events.json`** — статический фид (12+ событий: id, title, date, type, capacity, registered, status…).
- Фид генерируется из `public/js/data.js`; при изменении данных скрипт `ci/sync-events.js.sh` перегенерирует `events.json` (запускается локально или на этапе сборки).
- Контур 1 (`nauka-sistem-patfiz.waw0.amvera.tech/api/events`) проксирует этот фид с кэшем 5 минут и fallback-набором, отображает живые данные на странице «Мероприятия» и включает их в отчёты подразделений.
