## Назначение

Подсистема научных мероприятий: каталог конференций и событий, личный кабинет участника, панель организатора, отчетность и документооборот.

## Основные модули (по демо)

- Каталог мероприятий
- Ближайшие конференции и важные даты
- Личный кабинет
- Панель организатора
- Отчетность и документооборот
