# nauka-site-patfiz — Контур 2

**Сайт с научными мероприятиями.**

- 🚀 Деплой (Amvera): `nauka-site-patfiz.waw0.amvera.tech` (nginx, статический сайт из `public/`)
- 🔗 Смежный контур: [Контур 1 — система учета научной работы](https://github.com/Kroshkos/nauka-sistem-patfiz) (`nauka-sistem-patfiz.waw0.amvera.tech`)

## Структура репозитория

```
amvera.yml                 # конфиг Amvera (Docker-сборка)
Dockerfile                 # nginx:1.27-alpine, отдаёт public/ на порту 8080
public/index.html          # демо-версия сайта мероприятий (автономный HTML)
demo/nauka-site-demo.html  # исходник демо
```

## Запуск локально

```bash
# любой статический сервер, например:
python3 -m http.server 8080 --directory public
# или docker build -t nauka-site . && docker run -p 8080:8080 nauka-site
```

## Основные модули (по демо)

- Каталог мероприятий
- Ближайшие конференции и важные даты
- Личный кабинет участника
- Панель организатора
- Отчетность и документооборот
